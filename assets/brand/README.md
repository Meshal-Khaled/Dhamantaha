# Dhamantaha logo

Created on 2026-10-20 using the built-in imagegen tool after reviewing the project plans, update log, Android app styles and existing admin mark.

The receipt represents saved purchase records, the shield represents warranty protection, and the checkmark represents assurance. Teal follows the existing Android UI. The primary logo includes the Arabic name **ضمنتها** and English name **Dhamantaha**.

- `dhamantaha-logo.png`: primary stacked logo with both names, 1214 × 1295 pixels, transparent background.
- `dhamantaha-symbol.png`: standalone symbol, 1254 × 1254 pixels, transparent background, for compact branding and future icon preparation.

These are raster PNG source assets. The standalone symbol is not a generated Android adaptive-icon resource set. No existing app assets were replaced.

## Generation prompts

### Primary logo

```text
Use case: logo-brand.
Asset type: primary brand logo for an Arabic and English Android/web warranty wallet, Dhamantaha (ضمنتها).
Primary request: Create one polished, original production-quality logo on a genuinely transparent background. The product scans purchase receipts, organizes warranties and reminds people before expiry. Its existing UI uses teal #0f766e, dark teal #115e59 and ink #14201f. Its initial admin favicon uses a receipt with a checkmark; develop that conceptual direction into a confident, distinctive consumer app identity.
Design: a single bold, clean geometric symbol that fuses a protected receipt with a shield and an integrated checkmark. The outer teal silhouette should suggest both a paper receipt and reassuring protection; the checkmark is a broad transparent negative-space cutout. Softly rounded corners, balanced negative space, very few parts, an immediately recognizable silhouette at app icon size. Flat solid teal #0f766e; no gradients, shadows, 3D, textures, ornamental flourishes or thin fussy details.
Composition: vertically stacked lockup, centered symbol above a beautifully typeset Arabic wordmark, and a much smaller English name below. Spacious, carefully balanced proportions. Arabic typography: bold contemporary geometric Arabic, expertly connected and correctly dotted, calm and friendly. English typography: medium-weight modern humanist sans serif, discreet, elegantly spaced. All typography dark teal #115e59. The symbol is the hero.
Text (verbatim): Arabic "ضمنتها", English "Dhamantaha". Arabic letters in reading order: ض م ن ت ه ا. Preserve accurate Arabic shaping and dots. No tagline, extra text, labels, presentation panels, mockups, frames, or other marks.
Output: one isolated finished logo with actual alpha transparency and crisp vector-like contours, ample clean transparent margins, suitable for headers, splash screens and marketing.
```
