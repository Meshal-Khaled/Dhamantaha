# Dhamantaha — frontend-only instructor demo

- Home page: only two sample receipts approaching a return deadline.
- **Receipts** tab: all four sample products with separate detail links.
- Add Receipt and Settings tabs retained.
- Settings includes Appearance (light/dark, normal/large), Language (Arabic/English), Notification preferences (warranty, returns, refunds), Face ID mock toggle, and Sign Out demo.
- Language switch is **only** in Settings, not in page headers.
- Every variant has the same navigation and separate product detail pages with receipt photo and download.
- **HTML + CSS only**, no JavaScript and no backend. Toggles are visual only, do not persist. All receipt data and countdown values are static samples; notifications are not delivered.

Open `index.html` with Live Server to begin.
